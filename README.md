# BonziRECHAT

## Dependencies
- Node.js and npm (Be sure to download this)
- Ruby
- Sass
- Git
- Cordova (Optional)

## Setup
Download the source for this software, and unzip it somewhere you'd like it to be.
```
git clone -b 1.6.0-pre-shutdown https://github.com/HD5Editsisback/BonziRECHAT/
cd BonziRECHAT
```

### Server
Then, click here in the file explorer:
...then type "cmd", and press Enter.

Run this code in your command line:
```
npm install
```
Then run this:
```
node index.js
```
After this, BRC will be accessible on port 3000. (http://localhost:3000/)
